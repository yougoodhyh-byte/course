# 教学工作台微信小程序

此目录可直接作为微信开发者工具项目打开，并与现有 GitHub Pages 网站共用同一个 Supabase course 项目和同一份 teaching_workspaces.payload 数据。

## 已实现
- 仅允许 1661531189@qq.com 登录
- 课表：当前周、前后周、添加/编辑/删除课程、多周、多节、地点、进度
- 今日重要提醒：完成 / 擦除
- 重要事项：新增、修改、完成、删除
- 其他服务默认折叠，顺序：校车 → 考勤 → 校历
- 校车：方向优先、日期/工作日/周末筛选
- 校历：秋季/春季、周次、关键事件、上课和考试时间
- 考勤：计量经济学、数字经济专业认知、微观经济学
- 考勤列顺序：姓名 → 日期 → 学号（最后一列，学号不固定）
- 1 显示绿色，-1 显示红色，- 为未登记
- 打开某门课程考勤后，自动定位到距离当前时间最近的一次课；只有实际处于该课上课节次内才给该列红色边框
- Excel 学生名单导入与单门/全部考勤 xlsx 导出
- 网站与小程序通过 Supabase 共用并同步同一份数据

## 在微信开发者工具打开
1. 选择“导入项目”，项目目录选 wechat-miniprogram。
2. 当前 project.config.json 使用 touristappid，便于先打开项目；正式上传前替换为你自己小程序的 AppID。
3. 在微信公众平台后台的“开发设置 / 服务器域名”中，把下面地址加入 request 合法域名：
   https://oyihlolzwncfwuphidhw.supabase.co
4. 开发阶段如果域名尚未配置，可在开发者工具临时关闭“校验合法域名”；正式版必须配置。
5. 登录时使用与网站完全相同的密码。
